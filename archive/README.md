# Archive

Earlier analyses are kept unchanged for provenance. Do not use them for the manuscript numbers.

- `v1.0/` is the original release (Zenodo 10.5281/zenodo.18983306). It used a centroid re-implementation of PAM50, and its stability and biology files come from the secondary five-class run. Superseded.
- `v1.1/` adds canonical genefu and the PAM50-gene and 3,000-gene control arms in METABRIC, using all METABRIC genes. Its METABRIC conclusions agree with v1.2 (logistic regression on the 50 PAM50 genes: 0.879 macro-F1 in both).
